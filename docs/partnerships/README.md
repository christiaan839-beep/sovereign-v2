# Partnership door-openers

**Five concrete one-page briefs.** Each is sender-ready: copy the
body, paste into the partner's published partnerships address, send.
Track responses + follow-ups in `docs/partnerships/STATUS.md`
(create on first send).

## Why these five

The Wave 73 strategic review identified the five highest-leverage
doors. Each one buys a different asset:

| Partner   | What we gain                                          | What they gain                                                        |
| --------- | ----------------------------------------------------- | --------------------------------------------------------------------- |
| Anthropic | Citation in Claude regulatory enterprise docs         | Apache-2.0 receipt layer that makes Claude calls regulator-defensible |
| NVIDIA    | NIM Connect + GPU credits + Healthcare AI summit slot | FDA SaMD + PCCP rule packs for their healthcare AI vendors            |
| Google    | $200K Cloud credits + Vertex AI Model Garden listing  | Open-source verifier as a Vertex extension                            |
| OpenAI    | Citation in OpenAI's enterprise compliance docs       | Apache-2.0 wrapper that mints VAOS receipts around their API calls    |
| NIST      | Citation in AI RMF / 600-1 implementing guidance      | Cryptographic primitive that operationalizes their "audit trail" rec. |

## How to use each brief

1. **Read the brief.** Each is ≤ 1 page.
2. **Personalize the opener** — find the recipient on LinkedIn, reference one shipped product of theirs.
3. **Send from your own email.** Sender deliverability > template polish.
4. **Track in STATUS.md.** Sent / opened / replied / blocked / meeting / signed.
5. **Follow up at 7 + 14 + 30 days** if no response. Then archive.
