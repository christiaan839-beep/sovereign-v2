## 2025-05-24 - DoS Vulnerability in timingSafeEqual\n**Vulnerability:** `crypto.timingSafeEqual` throws an unhandled exception (DoS) if the buffer lengths do not match. Using string `.length` comparison before converting to Buffers is insufficient for multi-byte UTF-8 strings. \n**Learning:** Checking the length of a UTF-8 string is not the same as checking the length of the converted Buffer. An attacker could pass a payload with equal string length but unequal byte length, causing the Node server to crash.\n**Prevention:** Always compare buffer lengths *after* converting strings to buffers (`bufA.length === bufB.length`) before passing them to `crypto.timingSafeEqual`.
