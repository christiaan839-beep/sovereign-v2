## 2024-07-31 - [Keyboard Accessibility for Hover Actions]
**Learning:** Found several hover actions in NotificationBell, NotificationCenter, and NoteNode using `opacity-0 group-hover:opacity-100` without any explicit focus management or keyboard accessibility considerations. Keyboard users cannot tab to or use these actions effectively when they are hidden only visually (via opacity) and lack a `focus-within` trigger on the parent container, or they tab to them and cannot see they are focused.
**Action:** When hiding elements visually for mouse users (via hover), always add `focus-within:opacity-100` to the parent so they appear when a keyboard user tabs into them, and apply explicit `focus-visible` styles to the interactive elements themselves so the user knows what has focus.
