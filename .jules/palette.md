## 2024-06-11 - Adding Focus Visible Styles to Core Components
**Learning:** Found that the core Button.tsx component in this repository lacks explicit focus indicators for keyboard navigation, making the application heavily reliant on mouse interactions and failing basic WCAG requirements for keyboard operability. Since the brand uses a primary cyan color, applying a consistent focus ring matching this branding is critical for a cohesive and accessible experience.
**Action:** When working on UI components or performing UX reviews in this repository, always explicitly add focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[#00B7FF] to interactive elements (buttons, inputs, links) to ensure consistent keyboard accessibility without disrupting mouse-click aesthetics.
