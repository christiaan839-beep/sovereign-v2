Cyan = audit / infrastructure / trust surfaces (verifier, trust, spec, receipts).
Copper #B5532C = marketing / agency / playbooks surfaces (hero, pricing, industries).

**Why:** Dual-accent rule is owned by docs/design-system/brand-colors.md. CLAUDE.md says to read it before adding any accent color. Off-brand accents (emerald, violet, purple gradients) on vertical or pricing pages dilute the rebrand.

**How to apply:** When reviewing or generating UI:

- Vertical pages MUST pick cyan (audit-coded vertical: banking/defense/CSRD) or copper (marketing-coded vertical: agencies/realestate). Today some use random violet/emerald/purple — that is slop.
- Pricing page emerald/cyan/blue/teal gradients are all off-brand. Pro tier "Most Popular" badge should be copper; Enterprise/Team should use cyan accent ONLY if positioned as audit-tier.
- Never combine three accents in one card grid.
