## 2025-05-15 - [Sanitize HTML string interpolation]
**Vulnerability:** XSS vulnerability when rendering <script> tags dynamically using dangerouslySetInnerHTML, where only quotes were removed from the injected origin.
**Learning:** When sanitizing data for HTML string interpolation or dangerouslySetInnerHTML, stripping only quotes is insufficient to prevent XSS. Attackers can use angle brackets to break out of the tag context.
**Prevention:** Always ensure angle brackets (<, >) are also stripped or encoded to prevent breaking out of the tag context.
